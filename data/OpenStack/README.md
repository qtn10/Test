# data/OpenStack/

Raw OpenStack Nova logs: `openstack_normal1.log`, `openstack_normal2.log`, `openstack_abnormal.log`, plus `anomaly_labels.txt` listing the VM instance IDs known to be anomalous.

`drain/` holds the Drain log-parsing algorithm's output (structured CSV + template list), generated by `src/processing/openstack_processor.py`.

Source: Loghub collection, Zenodo record 8196385 (https://zenodo.org/records/8196385).
